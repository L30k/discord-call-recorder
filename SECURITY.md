# Segurança / Security

Não publique vulnerabilidades com exploração detalhada, gravações, configurações pessoais
ou logs sem revisão em issues públicas. Use a opção **Report a vulnerability** na aba
Security do GitHub se estiver disponível; caso contrário, abra uma issue sem detalhes
sensíveis solicitando um canal privado ao mantenedor.

Do not disclose exploit details, recordings, personal settings or unredacted logs in public
issues. Use GitHub Security → Report a vulnerability when available; otherwise request a
private contact channel in an issue without sensitive details.

O projeto ainda não tem uma versão estável publicada nem prazo garantido de correção.
There is no published stable version or guaranteed response time yet.
